# Introduction
This dataset provides insight into consumer purchasing behavior in a retail environment. It gathered data on how consumers shop, spend, and make decisions. I decided to create some simple queries to see some insights into consumer purchasing behavior as well as create an interactive dashboard on Power BI purposely using several visuals to show my understanding of Power BI.

# Tools I Used
- The dataset came from https://www.kaggle.com/datasets/wardabilal/customer-shopping-behaviour-analysis

- **SQL** : The programming language used to query teh database

- **PostgreSQL** : The database management system used

- **Git & GitHub** : Used to store and track projects

-  **Power BI** : Created an interactive dashboard as well as visualize the query findings
